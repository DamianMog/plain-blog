A short, honest list of what I do well. Edit `src/content/pages/expertise.md` to replace it with yours.

## Backend

Designing and building APIs and services that stay simple under load.

- Go, TypeScript (Node.js) and Python
- PostgreSQL, SQLite, Redis
- REST and a little GraphQL, when it earns its place
- Background jobs, queues and scheduled tasks

## Frontend

Fast pages that work with or without JavaScript.

- Semantic HTML and modern CSS
- Astro, Svelte and a restrained amount of React
- Accessibility, print styles and keyboard navigation

## Infrastructure

Boring, reliable deployments on hardware you can afford.

- Linux, Nginx and systemd
- Docker and Docker Compose
- CI pipelines, backups and monitoring that someone actually reads

| Area | Experience |
